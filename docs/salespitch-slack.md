:zap: *Introducing QueryForge* — The Desktop BigQuery Client You've Been Waiting For

---

Tired of the BigQuery web console? :sleeping: 

*QueryForge* is a *native desktop app* that makes working with BigQuery fast, powerful, and actually enjoyable.

---

:star2: *Why QueryForge?*

:rocket: *Blazing Fast Performance*
• Canvas-based results rendering — handles *500K+ rows* without breaking a sweat
• SQLite-backed result caching — no memory issues with large datasets
• Instant query execution with real-time progress

:brain: *Smart Editor*
• Full Monaco editor (same as VS Code!) with BigQuery-aware autocomplete
• Intelligent suggestions for tables, columns & functions
• One-click SQL formatting

:card_file_box: *Multi-Tab Workflow*
• Work on multiple queries simultaneously
• Split editor view for side-by-side comparison
• Tabs persist across sessions — pick up where you left off

:robot_face: *Built-in AI Assistant*
• Integrated chat sidebar for query help
• Supports OpenAI, Azure OpenAI, Gemini & Claude
• Context-aware — understands your schema

:mag: *Schema at Your Fingertips*
• Browse datasets & tables in a tree view
• View table schemas, partitioning & clustering info
• Search across all tables and columns instantly (`Cmd+P`)
• Click any table name in results to inspect its schema

:floppy_disk: *Never Lose Your Work*
• Save & organize queries locally
• Full query history with one-click re-run
• Export results to CSV/JSON

:art: *Beautiful & Customizable*
• Light & dark themes
• Resizable panels
• Remembers your window layout

---

:lock: *Secure by Design*
• Uses your existing GCP credentials (ADC or service account)
• All data stays local — nothing sent to external servers
• Open source & auditable

---

:computer: *Available for macOS, Windows & Linux*
