# QueryForge Quickstart 🚀

*Copy and paste this into Slack*

---

:rocket: *Getting Started with QueryForge in 5 Minutes*

---

*1️⃣ Install*
```
git clone <repo-url>
cd QueryForge
npm install
npm run build
npm start
```

---

*2️⃣ Connect to BigQuery*
• Launch app → Click *Configure Connection*
• Enter your GCP Project ID
• Choose auth method:
  ◦ `Application Default Credentials` (recommended) - uses your `gcloud auth application-default login`
  ◦ `Service Account Key` - paste JSON or provide path
• Click *Connect* :white_check_mark:

---

*3️⃣ Run Your First Query*
• Type SQL in the editor
• Press `Cmd+Enter` (Mac) or `Ctrl+Enter` (Win/Linux)
• Results appear below :chart_with_upwards_trend:

---

*4️⃣ Essential Shortcuts*

:keyboard: *Execute Query* → `Cmd+Enter` / `Ctrl+Enter`
:keyboard: *New Tab* → `Cmd+T` / `Ctrl+T`
:keyboard: *Save Query* → `Cmd+S` / `Ctrl+S`
:keyboard: *Format SQL* → `Cmd+Shift+F` / `Ctrl+Shift+F`
:keyboard: *Search Schema* → `Cmd+P` / `Ctrl+P`
:keyboard: *AI Assistant* → `Cmd+Shift+I` / `Ctrl+Shift+I`

---

*5️⃣ Quick Tips*
:bulb: Right-click any table in the sidebar for quick actions
:bulb: Click table names in results to view their schema
:bulb: Use the AI chat sidebar for query help
:bulb: Export results to CSV/JSON from the toolbar

---

:question: *Need help?* Check the README or use `Cmd+?` / `Ctrl+?` in-app
